# Questões 1 a 36

## Tema 1 – Estrutura de decisão if

1. Criar um programa que verifique se uma pessoa é maior de idade.
2. Criar um programa que verifique se um número é positivo.
3. Criar um programa que verifique se um aluno foi aprovado com nota igual ou superior a 7.
4. Criar um programa que verifique se um número é par.
5. Criar um programa que verifique se uma pessoa possui idade suficiente para votar, considerando a regra de idade definida no exercício.
6. Criar um programa que verifique se uma senha digitada corresponde à senha cadastrada.

## Tema 2 – Estrutura de decisão switch

7. Criar um programa que apresente o dia da semana conforme um número de 1 a 7.
8. Criar um programa que apresente o nome de um mês conforme um número de 1 a 12.
9. Criar um programa que simule um menu de opções: cadastrar, consultar e sair.
10. Criar um programa que identifique o turno de estudo: matutino, vespertino ou noturno.
11. Criar um programa que apresente uma operação matemática escolhida pelo usuário.
12. Criar um programa que classifique um conceito escolar, utilizando letras como A, B, C e D.

## Tema 3 – Estrutura de repetição while

13. Criar um programa que exiba os números de 1 a 10.
14. Criar um programa que exiba os números pares de 2 a 20.
15. Criar um programa que faça uma contagem regressiva de 10 até 1.
16. Criar um programa que calcule a soma dos números de 1 a 100.
17. Criar um programa que apresente a tabuada de um número informado pelo usuário.
18. Criar um programa que solicite uma senha até que o usuário digite a senha correta.

## Tema 4 – Estrutura de repetição do while

19. Criar um programa que exiba os números de 1 a 10.
20. Criar um programa que apresente os números ímpares de 1 a 19.
21. Criar um programa que faça uma contagem regressiva de 5 até 1.
22. Criar um programa que apresente a tabuada de um número informado pelo usuário.
23. Criar um programa que exiba um menu até que o usuário escolha a opção de sair.
24. Criar um programa que solicite um número positivo até que o usuário digite um valor válido.

## Tema 5 – Estrutura de repetição for

25. Criar um programa que exiba os números de 1 a 100.
26. Criar um programa que exiba os números ímpares de 1 a 50.
27. Criar um programa que faça uma contagem regressiva de 20 até 0.
28. Criar um programa que apresente a tabuada de um número informado pelo usuário.
29. Criar um programa que calcule o fatorial de um número inteiro não negativo.
30. Criar um programa que calcule a soma dos números pares de 1 a 100.

## Tema 6 – Arrays

31. Criar um array com cinco números inteiros e exibir todos os seus elementos.
32. Criar um array com cinco nomes de pessoas e apresentar cada nome.
33. Criar um array com seis notas e calcular a média dos valores.
34. Criar um array de números inteiros e identificar o maior elemento.
35. Criar um array de dez números e contar quantos são pares.
36. Criar um array com cinco elementos, alterar um dos valores e exibir o array atualizado.
